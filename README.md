**BICKE – Smart Bike Lock**

  BICKE is an IoT-based smart bike lock system designed to improve bicycle parking security through automated locking, RFID authentication, and mobile application integration.

**Features**

  -RFID-based access
  
  -Automatic locking and lock verification

  -Real-time lock status monitoring

  -Parking history and duration tracking

  -Parking cost calculation

  -Mobile application integration with Firebase

**Hardware**

  -ESP32

  -RFID Reader (MFRC522)

  -IR Sensor

  -MG996R Servo Motor

  -Limit Switch

  -OLED Display

  -18650 Batteries and LM2596 Module

**Technologies**

  -ESP32

  -Firebase

  -Mobile Application
